# comparador-de-carros

Meu primeiro projeto em python. Decidi fazer esse programa relacionado a algo que gosto, carros, pois essa é minha migração de 'C' que é minha primeira linguagem de programação, a qual comecei a aprender recentemente também.

## O que o projeto faz

Funciona como um sistema para uma loja de carros:

-Armazena veículos de acordo com a necessidade; 
-Lista todos os veículos na ordem em que foram cadastrados; 
-Possuí um filtro de busca (assim como, webmotors.com e olx);
-Pode realizar comparações entre dois veículos escolhidos pelo usuário (me baseei em sites como, o tudocelular.com);
-Há possibilidade de excluir algum veículo cadastrado (não há limites de exclusão, porém, é necessário rodar o código quantas vezes forem necessárias);
-E por fim, pode simplesmente escolher sair do programa;

Há alguns veículos salvos na pasta "carros.json" como demonstração. Me diverti bastante fazendo esse código, aprendi muito também, certamente há pontos a serem melhorados, mas para uma primeira experiência, estou bastante satisfeito.
